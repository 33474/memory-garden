# Memory Garden

Memory Garden 是一个个人记忆记录与可视化原型。它把生活、旅行、感官、收藏和学习记录组织成会呼吸的主题花园、档案索引与时间生长线。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。默认开发地址通常为 `http://127.0.0.1:5173/`。

## 构建与预览

```bash
npm run build
npm run preview
```

## 页面

- 产品原型：`/`
- Agent 迭代记录：`/?view=process`

迭代记录只包含 Prompt 原文和截图；评价标准与复盘尚未开始。
